# Local configuration

1. Install Android SDK and let Android Studio create `local.properties`.
2. Download the Firebase Android configuration for package `com.example.datn_caregiver` and save it as `app/google-services.json`.
3. Build with `.\gradlew.bat assembleDebug`.

`app/google-services.json` and `local.properties` are ignored by Git. Do not commit credentials, service account files, or build logs.
